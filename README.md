# mini_console_calculator(java)
### About
This project is a simple console-based calculator written in Java.
It was developed as a practice project to understand core Java concepts
such as loops, collections, exception handling, and object-oriented design.
## Features
- Simple operations: addition, subtraction, multiplication, division, remainder
- Advanced operations on a list of numbers (sum, average, min, max)
- Input validation and error handling
- Custom exception implementation
- Operation history management (view & clear)
- Menu-driven console interface
## Technologies
- Java
- Maven
## How to Run
1. Clone the repository
2. Open the project in IntelliJ IDEA or any Java IDE
3. Run the `CalculatorApp` class
